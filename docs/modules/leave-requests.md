# Leave requests

One day off or one sick day. Staff, including sales, ask in Leave. A manager approves or rejects that request. A manager’s own request goes to a director. The result is texted to the employee and to the directors.

Each person may request one day off in a calendar month. A manager or director can raise or lower that number for everyone, or set a different number for one person, from 0 to 31. Sick days are not counted. A rejected day does not use the allowance. Days already approved stay when the number is lowered.

Director is a job role and a Legacy default. Pick it on the user form when Job role is None, or assign the Director job role. A person cannot decide their own day.

The Employees module and the Leave requests switch must be on. Each note is at most 300 characters. A day off is today through 90 days ahead. A sick day is from 2 days ago through 30 days ahead.
