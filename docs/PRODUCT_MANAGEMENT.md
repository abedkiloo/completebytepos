# Product management

How to build and keep the catalog: categories, sizes, colors, products, stock, and labels.

This is the store workflow. Super Admin turns features on; Manager (and Sales, if allowed) maintains the assortment.

## Who can change what

| | Super Admin | Manager | Sales |
|---|---|---|---|
| Products, categories, sizes & colors | Yes | Yes | If catalog access is on |
| Selling price / MRP | Yes | Yes, unless Module Settings turns it off | Off by default |
| Cost | Yes | Off by default | Off by default |
| Opening stock / stock adjust | Yes | Yes | Off by default |
| CSV import / export, bulk actions | Yes | Yes, if those product features are on | Usually no |

Sales catalog access also needs **Store settings → Allow sales to add products**.

Price, cost, or stock edits can go to **Pending approvals** when maker-checker is on. The live catalog stays unchanged until a checker approves.

## Recommended order

Do this once, then add products.

1. **Module Settings → Products** — turn on **Variants (size/color)** if you sell size or color options. Turn on **Product images** if you upload photos. CSV and bulk actions are optional.
2. **Categories** — parents first, then subcategories.
3. **Sizes & colors** — every size and color you will pick on products. Add them here *before* the product form.
4. **Products** — simple SKU, or a variant product (size/color combinations).
5. **Stock** — opening quantity on create; later use **Adjust stock** or **Manage Stock**.
6. **Print Barcode / QR** — shelf labels after the SKU exists.

POS only sells **active** products. Inactive items stay in the catalog but drop off the till.

## Categories

**Sales → Categories** (also under Inventory).

1. Add a parent (for example Sofas, Dining, Workshop).
2. Add subcategories under that parent, or use **+ Add subcategory** on the product form.
3. Keep names unique under the same parent.

You can also create a category from **Add product** without leaving the form. After you save it, it is selectable immediately.

Deactivate a category you no longer use. Delete only if nothing still needs it. Maker-checker may queue deactivate/delete.

## Sizes and colors

Needed only when **Variants (size/color)** is on. Menu: **Sales → Sizes & colors** or **Inventory → Sizes & colors**.

1. Open the **Sizes** tab → **Add size**. Name is required. Code is optional (example `L`). Display order controls the list order.
2. Open the **Colors** tab → **Add color**. Hex color is optional.
3. Leave **Active** on. Inactive sizes/colors stay in history but are hidden when you pick options on a product.

Add the size or color **first**, then open (or re-open) the product form. New sizes and colors appear in the picker as soon as they are created.

Each size name and code must be unique. If save fails, the name or code is already in use.

## Add a simple product (no size/color)

Use this for a single sellable item (one price, one stock count).

1. **Products → Add product**.
2. Name and category (subcategory optional).
3. Unit of measure.
4. Selling price (and MRP if your store shows it). Cost if you are allowed to edit cost.
5. Opening stock if you track inventory. Set **Low stock threshold** and **Reorder quantity**.
6. Image optional.
7. Save.

SKU and barcode are generated by the system. Do not type them.

After save, the product shows on the products list and on POS (or in Pending approvals if maker-checker queued it).

## Add a product with size or color

Example: one sofa model in several sizes, or fabric colors.

1. Confirm sizes and colors already exist under **Sizes & colors**.
2. **Products → Add product**.
3. Name and category as usual.
4. Check **This product has size/color variants**.
5. Set **Low stock threshold** and **Reorder quantity** on the product — they apply to every variant.
6. Build each sellable combination: pick a size and a color, click **Add variant**, then enter price (and MRP/cost/opening stock if those fields show) on that row.
7. Save. POS will ask for size/color when the cashier adds this product.

You do not set one selling price on the parent product. Each variant row has its own price and stock.

If the size or color list is empty, use the **Sizes & colors** link on the form, add the missing option, then return and add the variant.

To add another combination later, edit the product and use **Add variant** again.

## Edit a product

Open **Products**, find the row, **Edit**.

- Name, category, image, active/inactive — from the form.
- Price and cost — from the form if your role may edit them. Sensitive changes may need a reason and approval.
- **Stock quantity is not edited on this form after the product exists.** Use **Adjust stock** from the products list (or **Stock → Stock adjustment** / **Manage Stock**).

Click a product row to open the detail panel (price, stock, variants) without full edit.

## Products list

- Search by name or generated SKU/barcode.
- Filter by category, active, low stock, out of stock.
- **Adjust stock** on a row: +/− quantity and a reason.
- Bulk activate / deactivate / delete if **Bulk select and actions** is on.
- **Export / Import CSV** if that feature is on. Import updates matching catalog rows; review the file before you import.

Pending-approval badges mean a price, cost, stock, or catalog change is waiting. Until it is approved, POS still uses the current live values.

## Stock after the first save

| Need | Where |
|------|--------|
| Opening quantity | Product form, only when **creating** |
| Count is wrong | Products list → **Adjust stock**, or **Stock → Stock adjustment** |
| Move between branches | **Stock → Stock Transfer** |
| History | **Stock → Manage Stock** |

Variant products hold stock **per size/color row**, not on the parent.

## Labels

**Inventory → Print Barcode** or **Print QR Code**.

Search, generate missing barcodes if needed, select items, preview, print. Cashiers scan the label on POS.

## Common problems

**I added a size but cannot pick it on the product.**  
Save the size under **Sizes & colors**, then open Add/Edit product again. The picker loads the full size list (not only the first page).

**No “This product has size/color variants” checkbox.**  
Super Admin: **Module Settings → Products → Variants (size/color)**.

**Sizes & colors menu is missing.**  
Same feature flag. The page also reminds you if variants are off.

**Sales cannot open Products.**  
Enable **Sales: access Products & Categories** and **Allow sales to add products**. They still cannot change price, cost, or stock unless those extra toggles are on.

**Save says it needs a reason.**  
Maker-checker is on. Enter why the price, cost, or stock is changing, then confirm. A checker approves it under **Pending approvals**.

**POS does not show the product.**  
It must be **active**, not waiting on approval for its first create, and (for variants) have at least one combination with stock if you enforce stock at the till.

**Cannot change cost as manager.**  
Default: only Super Admin edits cost. Turn on **Managers: set cost of goods** if managers should.
